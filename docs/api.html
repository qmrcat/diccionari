API Consulta DISC

      

        Resultats en JSON. Tornar al cercador
      


      
1. Al navegador: api.html?p=paraula

      
Mostra el resultat en JSON. Per consultar-ne diverses alhora, separa-les per comes o repeteix
        p:

      
    
        
  • api.html?p=cases
    • 
        
  • api.html?p=casa,vaig,xyzzy
    • 
      

      
GitHub Pages només serveix fitxers estàtics: el JSON el construeix el JavaScript de la
        pàgina. Un programa que no executi JavaScript (curl, un servidor…) rebrà l'HTML, no el JSON. Per a
        aquests casos, fes servir les opcions 2 o 3.


      
2. Des d'una altra web: diccionari.js


<script src="js/diccionari.js"></script>
<script>
  Diccionari.consulta('cases').then((r) => {
    console.log(r.valida, r.estat);  // true "forma"
  });
</script>

      
La llibreria descarrega només els fitxers de dades que necessita i els guarda en memòria.


      
3. Els fitxers JSON directament

      
Normalitza la paraula (minúscules, sense accents, ni ·, guionets o apòstrofs) i agafa'n
        les tres primeres lletres: «Cases» → cases →
        dades/c/as.json. Hi trobaràs:

      
    
        
  • e[clau]: entrades del DISC [entrada, categoria, model]
    • 
        
  • f[clau]: formes flexionades [forma, entrada]
    • 
        
  • c[clau]: formes només del corrector de Softcatalà
    • 
      

      
La llista de fitxers existents és a dades/index.json.


      
Format de la resposta


{
  "paraula": "cases",
  "estat": "forma",          // entrada | forma | no-confirmada | no-trobada
  "valida": true,            // true per a «entrada» i «forma»
  "entrades": [],            // entrades del DISC amb aquesta grafia
  "formes": {                // null si no és una forma flexionada
    "escrites": ["cases", "casés"],
    "de": [{ "entrada": "casa", "categoria": "f.", "descripcio": "nom femení", "model": "203" }, …]
  },
  "corrector": [],           // només amb «no-confirmada» (verbs irregulars…)
  "suggeriments": []         // entrades que comencen igual, si no és vàlida
}
